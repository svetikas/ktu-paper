# ktu-paper

This repository contains a Typst template for academic papers at the Kaunas University of Technology, Faculty of Informatics.

I successfully wrote and defended a final Bachelor's thesis written with this template and continue to use for writing other reports.

## Initiating the template
Install the downloaded template under the following directory:
- Linux: `~/.local/share/typst/packages/local/ktu-paper/0.5.0/`

And then initiate a new project:
```sh
typst init @local/ktu-paper:0.5.0
```
